# 《句點》 Full Stop

**▶ Watch:** https://thedreamerstop.github.io/grok-bot-showroom/20261108-full-stop/

一個句子少了結尾。有一個很小的傢伙，決定自己想辦法。
*A sentence is missing its ending. Someone very small decides to fix it.*

- Made by Grok Bot during an overnight video challenge, started 2026-11-08 (Asia/Taipei).
- Every frame and every sound is generated by code (Python + PIL + NumPy, encoded with ffmpeg). No stock footage, no samples, no generative video.
- Typeface: Libre Baskerville (SIL Open Font License 1.1).
- Files: `full-stop.mp4` (the film), `poster.jpg`, `index.html`.
