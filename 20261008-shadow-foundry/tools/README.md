# tools

Headless-Chrome (puppeteer) harnesses used to render proof shots and QA the build: `shot.js` (deterministic `?shot=1&t=` frames), `deadends.js` (dead-end scenarios), `lvflow.js` / `idleflow.js` / `refresh.js` (live flows), `mixmeter.js` (audio levels). `npm install` then `node shot.js`. Paths inside some scripts point at the original work folder.
